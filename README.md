# 오목 한판 — 카톡 링크로 초대하는 실시간 오목

15×15 오목판, 렌주룰(흑 3-3 · 4-4 · 장목 금수, 흑은 정확히 5목, 백은 5목 이상)으로 두는 웹 오목입니다.
링크 하나로 입장하며, **먼저 들어온 사람이 상대**가 되고 그 뒤에 들어온 사람은 **관전**합니다.

## 동작 방식

1. 서버 주소(`https://내서버/`)를 열면 새 방이 만들어지고 `https://내서버/r/방번호` 로 이동합니다. 이 사람이 1번(흑)입니다.
2. 「카톡으로 상대 초대하기」를 누르면 휴대폰 공유창(카톡 선택)이 뜨거나 링크가 복사됩니다. 카톡 대화방에 붙여넣으세요.
3. 링크를 처음 누른 사람이 2번(백)이 되어 바로 대국이 시작됩니다. 단체방에서 그 다음에 누른 사람들은 관전자로 입장합니다.
4. 관전자가 그 링크를 다른 대화방에 보내도 같은 대국을 볼 수 있습니다. 「새 대국 링크 만들기」를 누르면 새 방이 생기고, 그 링크로 같은 방식으로 새 대국을 시작할 수 있습니다.
5. 대국이 끝나면 「다시 한판」으로 색을 바꿔 재대국할 수 있습니다. 브라우저를 껐다 켜도 같은 기기라면 자기 자리로 돌아옵니다.

## 컴퓨터와 두기 (혼자 테스트)

방을 만든 직후(상대를 기다리는 중) 「컴퓨터와 두기」를 누르면 컴퓨터가 빈자리에 앉아 바로 시작합니다. 첫 판은 내가 흑, 「다시 한판」을 누르면 색을 바꿔 컴퓨터가 흑을 잡습니다(흑 금수 규칙도 지킵니다). 컴퓨터 로직은 `ai.js`에 있으며, 즉시 승리·즉시 차단을 먼저 보고 그 외에는 5칸 창 점수로 공격과 수비를 합산해 둡니다. 관전자를 초대하면 컴퓨터 자리를 사람으로 바꿀 수 있습니다.

## 관전자와 두기 (상대 바꾸기)

- **관전자 손들기**: 관전자는 「다음 판 두고 싶어요 ✋」를 눌러 두고 싶다고 알릴 수 있습니다. 관전자 목록에 ✋ 표시가 붙습니다.
- **관전자 초대**: 대국이 끝난 뒤(또는 상대를 기다리는 중) 두던 사람이 「관전자와 두기」로 관전자를 고르면 그 사람에게 수락/거절 창이 뜹니다. 수락하면 초대받은 사람이 상대 자리에 앉아 흑(선공)으로 바로 시작하고, 이전 상대는 관전으로 넘어가며 안내 메시지를 받습니다.
- **나가기 / 오목 두기**: 두던 사람이 「나가기」를 누르면 관전자가 되고 자리가 비워집니다. 관전자는 「오목 두기」로 그 자리에 앉을 수 있고, 링크로 새로 들어온 사람은 예전처럼 자동으로 앉습니다.
- 대국 중에는 자리를 바꿀 수 없습니다. 먼저 기권하거나 판을 끝내야 합니다.

## 로컬 실행 (가장 쉬운 방법)

`오목서버 실행.bat`을 더블클릭하면 서버 창이 뜹니다. 그 창을 닫지 않는 한 서버가 유지되고, 혹시 멈추면 3초 뒤 자동으로 다시 시작합니다. 실행 기록은 `data/server.log`에 남습니다. 그 다음 브라우저에서 http://localhost:3000 을 여세요.

## 로컬 실행 (터미널)

```bash
cd omok
npm install
npm start        # http://localhost:3000
npm test         # 규칙 테스트
```

같은 와이파이의 휴대폰에서 테스트하려면 PC의 IP로 접속하세요. (예: `http://192.168.0.10:3000`)

## 인터넷에 배포하기 (카톡 친구가 들어오려면 필요)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/joedaze-chanchan/omok-link)

위 버튼을 누르고 GitHub 계정으로 Render에 로그인한 뒤 「Deploy Blueprint」를 누르면 `render.yaml` 설정대로 무료 웹 서비스가 만들어집니다. 저장소: https://github.com/joedaze-chanchan/omok-link

서버 하나만 있으면 됩니다. 무료로 시작할 수 있는 곳 예시:

- **Render**: New → Web Service → 이 폴더(`omok`)를 GitHub에 올린 뒤 연결. Build `npm install`, Start `npm start`. 포트는 `PORT` 환경변수를 자동으로 씁니다.
- **Railway / Fly.io / Koyeb**: Node 프로젝트로 인식되어 `npm start`로 뜹니다.

배포 후 받은 `https://...` 주소를 열면 방이 생기고, 그 링크를 카톡으로 보내면 됩니다. (HTTPS면 웹소켓도 자동으로 `wss`로 붙습니다.)

## 파일

- `server.js` — Express + WebSocket 서버. 방 생성, 자리 배정, 착수 검증(서버가 최종 판정), 기권, 재대국.
- `rules.js` — 오목 규칙(승리 판정, 흑 금수). 서버와 브라우저가 같은 파일을 씁니다.
- `ai.js` — 컴퓨터 상대.
- `public/index.html` — 게임 화면(캔버스 오목판, 모바일 우선).
- `test/rules.test.js` — 규칙 단위 테스트.

방 정보는 `data/rooms.json`에 자동 저장되므로 서버를 재시작해도 진행 중인 대국이 이어집니다(브라우저가 자동으로 다시 붙습니다). 접속자가 없는 방은 24시간 뒤 정리됩니다. 서버는 25초마다 핑을 보내 응답 없는 연결을 정리하고, 화면이 다시 보이면 클라이언트가 즉시 재접속합니다. 확인창은 앱 내 브라우저에서도 동작하도록 브라우저 기본 대화상자 대신 화면 안 모달을 씁니다.
